# Product-first catalog + Portada Pro

Internal release note for the product-first storefront iteration.

- Mobile catalog defaults to two product cards per row.
- Shoppers can switch between denser and larger product views; preference is stored locally.
- Desktop respects the merchant's 2/3/4 products-per-row choice.
- Main catalog cards prioritize image, product name, brand, price, promotion and CTA.
- Portada adds live desktop/mobile preview, title font choice and semantic title sizing.
- Font choices are presented visually instead of as technical font settings.
- Supabase adds only `hero_title_font` and `hero_title_scale` to `store_content`.
