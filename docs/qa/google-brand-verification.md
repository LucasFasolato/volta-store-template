# Google OAuth brand verification

VOLTA uses a public homepage at `https://voltastore.app` so Google reviewers can verify the product name, purpose, legal links, and OAuth data usage without authenticating first.

## Google Auth Platform values

- App name: `VOLTA`
- Homepage: `https://voltastore.app`
- Privacy policy: `https://voltastore.app/privacy`
- Terms: `https://voltastore.app/terms`
- Authorized production domain: `voltastore.app`
- OAuth data access: basic identity only (`userinfo.email`, `userinfo.profile`, `openid`)

The homepage explicitly describes VOLTA as a platform for creating a professional store, organizing products and categories, and sending orders to WhatsApp. It also explains that Google sign-in is used only for authentication and does not request Gmail, Drive, Calendar, or other sensitive Google data.
