# VOLTA STORE — Referencias UX/UI aprobadas

Estas láminas documentan la dirección visual aprobada para la productización premium de VOLTA STORE. No son assets del storefront: son referencias internas para mantener consistencia al diseñar, implementar y hacer QA.

## Boards

- `volta-store-board-01.jpg` — primera consolidación de pantallas y lenguaje visual.
- `volta-store-board-02.jpg` — sistema completo admin / apariencia / storefront / componentes.
- `volta-store-board-03-final.jpg` — tanda final aprobada, con flujos operativos, estados y responsive.

## Principios que deben preservarse

1. Funcionalidad y claridad antes que decoración.
2. Cada pantalla debe entenderse en pocos segundos.
3. Verde VOLTA como acento: CTA, selección, foco y estados importantes; no como ruido constante.
4. Fondos claros neutros + superficies blancas + bordes sutiles; sombras solo cuando una superficie realmente flota.
5. Menos pills y redondeos. Inputs/botones ~8–10 px; cards ~10–14 px; paneles grandes ~14–18 px.
6. Mobile no es desktop comprimido: navegación inferior, touch targets amplios y acciones sticky cuando ayudan.
7. Admin: Resumen / Apariencia / Productos / Configuración.
8. Apariencia: Estilos / Portada / Colores / Productos / Diseño / Fuentes / Secciones. Preview protagonista.
9. Activación: Portada / Primer producto / Estilo. El producto no necesita imagen para desbloquear el paso.
10. Storefront: navegar → elegir producto/variantes → agregar al pedido → continuar por WhatsApp. Nunca simular un checkout de ecommerce tradicional.
11. Los boards son una guía visual; la implementación debe respetar la lógica y los datos reales del producto, no copiar inconsistencias propias de una imagen generada.

## Estándar de QA

Antes de shipping revisar desktop + mobile, light + dark del admin, focus/teclado, reduced motion, loading/empty/error/save/upload, variantes, carrito, handoff a WhatsApp, portada y cambio de presets.
